# Lyne-like

A minimalist line-drawing puzzle game for phones, inspired by Thomas Bowker's
LYNE. TypeScript + Canvas, no engine, no runtime dependencies.

> The name is a placeholder. Puzzle *mechanics* are not protected, but the name,
> logo and art direction are — pick an original title before publishing.

## The rules

A board is a grid of pieces. Some cells hold a coloured **shape** (triangle,
diamond, square); some hold a neutral **hub** (the octagon with dots).

For each shape colour you draw **one continuous line**:

1. It starts at one **terminal** — a piece drawn inside a ring — and ends at the
   other terminal of the same colour.
2. It must pass through **every piece of its colour, exactly once**.
3. It moves between **touching cells, diagonals included**.
4. It may only travel over its own colour's pieces, or over hubs.

Two more rules bind the whole board together:

5. **Hubs must be crossed exactly as many times as they show dots.** Any colour
   may cross a hub, and a single line may cross one more than once — entering
   and leaving by different routes.
6. **Lines never overlap and never cross**, including two diagonals cutting
   through the same square. Hubs are the only place lines may meet.

There is no timer, no score and no way to lose. A wrong line is just redrawn.

## Playing

Press a terminal and drag. Drag backwards to undo a step. Press any piece
already on a line to grab it there and cut everything after it. Press a terminal
again to start that line over.

## Running it

```bash
npm install
npm run dev          # play at http://localhost:5173
npm test             # rules + every shipped level verified solvable & unique
npm run test:browser # drives real Chromium, solves levels with simulated drags
npm run gen          # regenerate the level pack
```

## How it is put together

```
src/core/       the game, independent of any rendering
  types.ts      board and cell model
  level.ts      ASCII level format, parsing, validation
  rules.ts      every legality rule — the single source of truth
  game.ts       interactive state: press, drag, retract, truncate
  solver.ts     exhaustive backtracking search
  generator.ts  seeded puzzle generation, verified by the solver
src/render/     canvas drawing and palette
src/levels/     hand-authored tutorials + the generated pack
```

Two decisions worth knowing:

**Every rule lives in `canExtend`.** Legality is enforced as you draw, not
checked at the end, so an illegal board is unreachable through play. The solver
and the player move through the exact same function — if the game lets you draw
it, the solver considers it, and vice versa.

**Puzzles are generated by drawing a solution first.** The generator random-walks
a line per colour, then reads the board off that drawing: cells touched once
become pieces, cells touched more than once become hubs with that many dots. A
solution therefore exists by construction, and the solver then discards any board
with more than one, so every shipped level has exactly one answer.

## Status

Playable core loop, 28 levels. Not yet built: audio, animation/juice, a level
select screen, and the Capacitor wrapper for iOS/Android store builds.

Known limit: the generator finds unique boards reliably up to about 6x6 with
three lines. Larger boards are usually ambiguous under random walking and need a
smarter search before harder packs can ship.
